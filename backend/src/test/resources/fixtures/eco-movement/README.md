# Eco-Movement sample

`locations.json` is a cut-down copy of one page of the Eco-Movement AFIR feed for Denmark
(NAP dataset 1170), fetched on 2026-10-26: four sites, at most two charge points each, with
their status entries. Data © Eco-Movement and the operators, licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). It contains no access token.
